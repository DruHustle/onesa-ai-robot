CURRENT IMPLEMENTED SCOPE

Test the workflow.
Understand the boundary.

01 · AUTHORITY

Separate approval

An authenticated operator creates a time-limited proposal and confirms it with a password. Model text and a connected socket cannot grant motion authority.

02 · SIMULATION

Measured movement

A synthetic joint follows bounded position, velocity and acceleration limits. Operators inspect timestamps, task outcomes and cancellation history in the private console.

03 · SAFE FAILURE

Stop on lost authority

Heartbeat loss, session expiry, cancellation and restart stop simulated execution. Reset requires confirmation and never resumes an earlier task.

CLOUD AND EDGE RESPONSIBILITIES

A clear route to robotics development.

The cloud API manages authenticated simulation state and task history. A separate synthetic edge agent can send scoped telemetry. ROS 2 message definitions are preparatory; physical control, camera, speech and action models need their own integration and safety qualification.

Development line

Software simulation is implemented. Hardware integration and physical safety certification remain separate future work.
