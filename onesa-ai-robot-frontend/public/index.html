CURRENT IMPLEMENTED SCOPE

Test the workflow.
Understand the boundary.

01 · AUTHORITY

Separate approval

An authenticated operator creates a time-limited proposal and confirms it with a password. Model text and a connected socket cannot grant motion authority.

02 · SIMULATION

Bounded simulation

A calculated synthetic joint follows explicit position, velocity and acceleration limits. Scenario readings are deterministic numeric fixtures, not camera recognition, OCR or validated physics.

03 · SAFE FAILURE

Stop on lost authority

Heartbeat loss, session expiry, cancellation and restart stop simulated execution. Reset requires confirmation and never resumes an earlier task.

CLOUD AND EDGE RESPONSIBILITIES

A clear route to robotics development.

Onesa Robot works independently with its own operator boundary and durable run journal. An optional read-only file from the AI Platform robotics interface can supply reviewed asset identity and telemetry snapshots; imports are disabled by default and grant no Robot access. No maintenance writes or physical commands are issued.

Development line

Deterministic skills and supervised inspection are the baseline. AI-assisted planning, learned policies and ROS 2 hardware adapters need separate evaluation. FluxVLA is an optional engineering evaluation; model inference is not configured.
