Development privacy

Onesa AI Robot is under development. This information covers the development website and protected software development and testing by authorized operators.

Information used during development

Operator access

The configured operator identity and access role identify authorized development users. A stored password hash is used to check sign-in and sensitive confirmations.

Essential sessions

An essential sign-in cookie keeps your authenticated session. Session information and security checks protect operator actions. Signing out revokes that session; a server restart clears active sessions.

Synthetic test history

Simulation proposals and outcomes include the operator identity, test values, timestamps and completion or cancellation state. Synthetic movement values can therefore remain associated with an operator.

Development diagnostics

Bounded synthetic-device events and necessary security and request metadata help test reliability, investigate failures and prevent unauthorized access.

Purpose and access

This information supports authorized software development, testing, authentication, security and review of simulation behavior. Protected history, telemetry and controls require backend authorization. Hardware integration is still being developed.

Storage and service providers

Vercel serves the website, Oracle Cloud Infrastructure hosts the protected API, Cloudflare provides HTTPS ingress and security controls, and Turso stores Robot history. These services can process connection, request and service metadata while providing their functions. Render is a former hosting provider, not the current API host; migration does not establish deletion of historical provider records.

Active sessions expire according to their configured lifetime. Synthetic-device audit events are bounded in process memory. Simulation history is stored separately for development validation and review; signing out does not delete that history. Provider logs and backups have their own lifecycles.

Purpose-specific legal basis, retention criteria and provider processing/transfer decisions remain awaiting the owner's recorded decisions. The development status and hosting description do not establish those approvals.
